# Vídeos da página inicial

Coloque nesta pasta os três arquivos abaixo. A página inicial detecta os arquivos automaticamente quando estiver sendo servida por um servidor local ou hospedada:

- `zenkai-tour.mp4` — tour pelo site
- `zenkai-ai.mp4` — apresentação da ZenkAI
- `zenkai-vscode-extension.mp4` — apresentação da extensão para VS Code

Os players usam Video.js e carregam apenas os metadados quando o arquivo está disponível.
