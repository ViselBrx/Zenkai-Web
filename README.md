# 🎬 Meu Player Local - RedeCanais

> ⚠️ **Aviso**: Este repositório é estritamente para uso privado. Não será permitido o acesso compartilhado.

## 📋 Sobre

Player HTML, CSS e JavaScript simples para assistir conteúdo do RedeCanais localmente, sem necessidade de acessar o site diretamente.

## 🚀 Como usar

1. Clone o repositório:
```bash
git clone https://github.com/ViselBrx/Videos-redecanais.git

```
2. Abra a pasta clonada localmente com o VsCode:

3. Inicie o servidor local:
```bash 
node server.js
```
4. Abra no navegador e teste o site.
